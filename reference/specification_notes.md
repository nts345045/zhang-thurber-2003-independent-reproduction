# Written-specification checks

Access date: 2026-10-09. These checks used publication text and tabulated
model descriptions. No original arrival data, model output, software, or
digitized plot values were used.

## A written alternative to the homogeneous starting model

Oppenheimer, D. H., F. W. Klein, J. P. Eaton, and F. W. Lester (1993),
*The Northern California Seismic Network bulletin, January–December 1992*,
USGS Open-File Report 93-578, Table 4, pp. 17–18, provides two profiles
attributed to Dietz and Ellsworth (1990):

| Profile | Depth z (km) | P velocity (km/s) |
|---|---|---|
| Loma Prieta, Pacific side (LOM) | 0, 2, 6.7, 24, 26 | 3.00, 4.95, 5.94, 6.64, 8.00 |
| Loma Prieta, North American side (LON) | 0, 2.5, 8.9, 24, 26 | 2.53, 5.44, 6.29, 6.69, 7.98 |

The table specifies gradient models. Footnote 2 states that station delays
were revised for a gradient-model adaptation. Thus these are documented
adaptations, not a verified transcription of the exact layered starting
model used by Zhang and Thurber. The target article does not identify the
side. Either named profile can support a disclosed sensitivity experiment;
testing both avoids silently resolving this ambiguity. Interpolation to the
target inversion depths introduces another explicit approximation.

Sources: [official report metadata](https://pubs.usgs.gov/publication/ofr93578),
[Table 4 in the report](https://pubs.usgs.gov/of/1993/0578/report.pdf),
[Dietz–Ellsworth publication metadata](https://pubs.usgs.gov/publication/70242141).
The PDF table and its footnotes were read as text in memory; no station-delay
data were retained or used.

## Figure 3 comparison conventions

The target article's p. 1878 prose specifies subtracting the recovered
solutions from the true velocity. The corresponding signed quantity is
therefore true minus recovered for panels 3c and 3d. Their caption says only
velocity difference and does not establish the sign by itself.

Caption 2 lists inversion depths 0, 3, 7, 11, and 16 km. The Figure 3
captions identify groups a–d and a half-grid-spacing hypocenter selection,
but do not enumerate plotted depths. Written text alone therefore does not
verify that all five inversion depths appear as published subpanels. Our
five-depth output must be identified as the generated grid-depth slices;
it is not evidence of an exact published layout match.

Sources: [author-posted manuscript text](https://www.researchgate.net/publication/215754286_Double-Difference_Tomography_The_Method_and_Its_Application_to_the_Hayward_Fault_California),
[complete author-posted manuscript PDF](https://www.researchgate.net/profile/Clifford-Thurber/publication/215754286_Double-Difference_Tomography_The_Method_and_Its_Application_to_the_Hayward_Fault_California/links/09e415094908102e39000000/Double-Difference-Tomography-The-Method-and-Its-Application-to-the-Hayward-Fault-California.pdf).

## Supplementary-material discovery

The original SSA issue table of contents defines an E icon for articles
with electronic supplements. The Zhang–Thurber entry (02190) has no such
icon or supplement link. The same issue has a supplement link for a
different article (03004), confirming that supplement links are represented
in this archive. The original target abstract page also lists no supplement.
No supplementary figures were identified. This is evidence about the
publisher's original listing, not proof that no later ancillary material
exists anywhere.

Sources: [SSA October 2003 issue contents](https://www.seismosoc.org/Publications/BSSA_html/bssa_93-5/ssa_toc_93-5.html),
[SSA original target abstract page](https://www.seismosoc.org/Publications/BSSA_html/bssa_93-5/02190.html).
