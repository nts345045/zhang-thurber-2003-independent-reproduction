# Failed-search delivery review

This independent readback checks the delivery manifest, completed evidence,
native identity joins, report quantities, local links, figure data, PDF text,
and two recorded LaTeX passes. It reads the saved rational intervals and
arithmetic results without reevaluating travel-time integrals or tracing rays.
The incomplete outer-accumulator experiment is outside its scope.

From the repository root, run:

```sh
python3 data/development/loma_failed_search_delivery_review_001/check.py
```

The helper writes `review.json` exclusively and refuses to overwrite an existing
review. For a repeat, first preserve the original review and run a copy of this
directory under `data/development/` with no `review.json`. Input hashes are
checked again before the result is saved. All consumed numerical reviews remain
unchanged.
