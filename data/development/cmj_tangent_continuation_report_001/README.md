# CMJ tangent continuation report checkpoint

This package records two ordinary LaTeX passes for the completed first-step
gradient readback and second tangent trial. Numerical outputs are read from
their separate, terminal evidence packages; compiling the report performs no
new numerical calculation. Run from the project root with
`PYTHONDONTWRITEBYTECODE=1 /usr/libexec/platform-python3.6 data/development/cmj_tangent_continuation_report_001/compile.py`.

The compiler script is unchanged from the preceding report checkpoint.
Compilation logs, PDF metadata, link/content validation and a visual review
will be retained here. Existing receipts are never overwritten.
