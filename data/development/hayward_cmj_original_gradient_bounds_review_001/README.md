# Saved original-gradient readback

Source preparation only. After the native audit is terminal and the checker receives a hash-bound `source_review.json`, this stdlib reader checks the unchanged original polygons and their saved internal component bounds. It makes no evaluator, primitive, compiler, integration, tracing or fitting calls.

The checker reuses pinned pure saved-data definitions for the original model, full catalog/native joins and exact physical-box projection. It reconstructs each incident-edge sum, preserves fixed endpoint omissions and aligned internal normal unavailability, compares raw C++ values with the saved ordinary bounds, and checks every error interval and squared norm. It retains the legacy activity-band projection separately. All source, runtime, terminal output, identifier-sidecar and outer-reaping pins are checked before writing a fresh review.
