# Authoritative metadata checkpoint

The Hayward input preparation now has authoritative metadata matches for all 42,236 initially selected P picks. EarthScope and NCEDC StationXML initially left 142 CMW1 picks unmatched because their channel coverage starts in 2000. The NCSN master station-history file supplies the missing historical SEED identities and operation dates: all 142 picks match uniquely, without aliases or backdating modern response metadata. The combined archive contains 4,980 metadata epochs and 521 NSLCs, including channels unused by the prepared subset. See the [metadata record](../authoritative/stations/README.md) and [CMW1 evidence](../authoritative/stations/investigation/cmw1_report.md).

For CCH1, CGP1 and CSU1, provider `Channel/Elevation` values of 107, 219 and 375 m are used as sensor elevations, with no second burial-depth subtraction. Conflicting published wellhead values and datum descriptions remain documented. CMW1 uses historical `ELEV=214 m` unchanged as receiver elevation, giving downward-positive model depth −0.214 km. Interpreting that field as sensor elevation is an explicit assumption; agreement with later StationXML is not independent survey verification. The external GPS-antenna flag is retained, historical burial depth remains unknown, and no numerical datum correction is imposed.

Written-source review establishes neither inclusion nor exclusion of these four stations in the original study. Their membership is recorded as unknown, which does not exclude them from the authorized independent subset. Only a documented study exclusion would change the reproduction station policy; the identified observations would remain available for a separate additional-data selection. Currently there are no confirmed study exclusions, so the two policy options alone do not select different observations.

The current [selection manifest](../hayward/selection_manifest.json) records **1,092 earthquakes, 37 physical station codes, 14,262 absolute P observations and 44,718 catalog differences**. The receiver table preserves 372 native metadata epochs across 62 NSLCs. The 4,584 event-pair links use catalog separation below 10 km, at least eight common channel geometries, and an undirected degree cap of ten. One component contains 1,058 events; 34 retained events have no differential links and retain absolute observations. No waveform-correlation observations are included, and the manuscript cohort remains unidentified.

Pairing requires the same NSLC and exactly equal reported latitude, longitude and receiver depth. Different metadata epochs may therefore share ray geometry without being merged into an invented epoch. Each differential observation retains both provider event/origin/arrival/pick identities, both native receiver indices (`station`, `station_j`), both epoch intervals and both source hashes. Of the catalog differences, 28,576 cross metadata epochs. Equal geometry does not establish unchanged timing calibration; the explicit flag permits later residual and sensitivity comparisons.

The [artifact audit](metadata_audit.json) verified raw-response provenance, station identifiers and preserved snapshots, and confirmed that all 104 previously tracked XML files were unchanged from its recorded Git revision. Prepared exclusions retain their identifiers and reasons. This checkpoint establishes documented inputs and metadata interpretations; it makes no claim of a validated inverse model or exact reproduction of the manuscript's figures.
