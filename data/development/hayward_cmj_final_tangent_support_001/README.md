This package is source preparation only. It assesses the exact two final polygons from `hayward_cmj_tangent_iteration_001`, after that run's independent saved-output review. One pass over the 2,058 final edges uses the existing interval tangent-component arithmetic at reciprocal-series degree eight (nine retained powers), one subdivision and 128 bound bits. The isolated primitive copy adds only the return of the action already available from its length and reciprocal average. It therefore provides ordinary available components and a final action enclosure without a second complete action pass. Net action is compared with the reviewed half-step starting polygons using their existing edge enclosures; geometrically identical edges contribute exactly zero to the paired difference.

For each of at most 65 aligned face patches, let global edge parameter `u = l + d t`, with `0 <= t <= 1`. The endpoint shape factors are `h0 = 1-u` and `h1 = u`. The four normal moments are

`M_j^side = -L d integral_0^1 h_j(t) v_n^side(t) / v(t)^2 dt`,

where `j` is the first or second endpoint and `side` is the neighboring minus or plus cell. The common face velocity is continuous and positive. An exact quadratic bound must prove `v_n^- - v_n^+ >= 0` over the complete patch. Failure of that condition leaves this supporting construction ineligible; the fit cannot override it.

A single constant `theta` in `[0,1]` selects `(1-theta) M_j^- + theta M_j^+` for both endpoint moments of each patch. This preserves their coupling. A finite stdlib cyclic coordinate least-squares proposal starts at `theta=0.5`, clips each coordinate update to `[0,1]`, and stops only when all binary64 coefficients are unchanged or after 10,000 complete sweeps. True zero columns are explicit. Unusable finite arithmetic does not produce a scientific-success claim. There is no residual tolerance, rank cutoff or claim that this restricted family achieves the smallest possible support residual.

The returned binary64 coefficients are promoted exactly to rationals for the interval assembly. Every ordinary adjacent-edge contribution remains, including entry and exit normal terms. Only actual physical-box bounds are projected; fixed endpoints are omitted. The final interval norm is an upper bound for this feasible full supporting-vector choice. Its lower bound is not a lower bound on the minimum support residual. A large witness is inconclusive; a small witness still does not establish first arrival or source-derivative accuracy.
