This package records one completed, unmodified `./rebuild.sh` invocation from detached commit `976d2590c60fae542e25c37c8b2352ff3765c6a1`. The 36 byte-exact files under [results/](results/) retain all eight final event tables, grids and histories, all three sampled ray/derivative/association tables, component checks and complete analysis metrics. The ray identifiers are invented event/receiver/observation-row associations, not provider, SEED or FDSN identities.

The expanded generated data, regenerated figures, compiled PDF and complete execution records remain preserved in the original local attempt; hashes and original repository-relative scientific paths are recorded here. This compact package neither replaces published baseline figures nor copies local process state or logs. Reused report figures are explicitly distinguished from freshly regenerated figures; file existence alone was not treated as regeneration evidence.

To repeat the same historical procedure, create a fresh detached checkout of the pinned commit, satisfy that commit's documented build/plot/TeX dependencies, set `OMP_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1` and `PYTHONDONTWRITEBYTECODE=1`, and invoke `./rebuild.sh` from its root. Put temporary, Matplotlib, XDG and TeX caches inside that checkout. The successful attempt used Python 3.11.9, NumPy 2.4.6, Matplotlib 3.11.2, CMake 3.26.5, GCC 8.5.0 and pdfTeX 1.40.19. It took 9,597 seconds with eight concurrent inversion processes; this is an observed duration, not a resource guarantee. PDF metadata can vary on replay. The later README dependency correction identifies Requests for the separate Hayward preparation imports; it did not change this pinned attempt.

The source snapshot already contains the historical eight-point quadrature and weighted ray-metric corrections. It is distinct both from the earlier 801-second baseline and from later integration-branch ray candidates. No source was changed to make the procedure pass.
