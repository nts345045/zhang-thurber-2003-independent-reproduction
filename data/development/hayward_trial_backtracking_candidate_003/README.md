# Pure local-stopping trial rejection candidate

This is an unexecuted, isolated change to the maintained guarded inverse call path. It copies the adopted D kernel unchanged. No maintained source, live executable, model, input, ray tolerance, weighting schedule, inverse schedule or failed run is replaced. `prepared.json` pins the maintained source at preparation and both complete source copies; `candidate.patch` changes only `src/main.cpp`.

A trial whose complete failed-ray roster contains only `local_stopping_failed` is not an evaluable point of the implemented forward objective. The candidate preserves its actual flags and native paths, then tries the next **existing** halved step. A trial cannot reach the objective or accepted state before the complete unchanged forward gate passes. Current/Jacobian and final-model failures remain fatal. Any additional finite, domain, endpoint, initializer or derivative failure remains fatal, as do unexpected worker/field exceptions and evidence I/O errors. The typed quality exception can reach the trial catch only after all failure/state/context writers have completed successfully.

The loop still tries at most 12 fractions, beginning at one, and constructs each source/model candidate afresh from the accepted state and the original LSQR increment. Source clamping and exponential velocity updates are unchanged. Weights and smoothing objective retain the existing arithmetic, including nonincrease acceptance; there is no recalculation of robust weights during backtracking. No unsupported trial is assigned a surrogate objective. If one or more pure-quality rejections occur but no trial reaches the objective, including mixtures with invalid velocity-model skips, the run stops explicitly. Valid but nonimproving objectives keep the original no-update/stage behavior. This is a local evaluability policy, not a global first-arrival or recovery guarantee.

Every attempted fraction is recorded in a fresh iteration trial ledger. Its `accepted` status means that the fixed-weight objective criterion passed for that fraction; later current/final forward checks and the run completion remain separate requirements. Rejected rays use unique iteration/trial prefixes and retain full native status, failed paths, trial events/grid and accepted events/grid. Existing artifact paths, including dangling symlinks, are refused. The conventional last-accepted files remain a current-state convenience; unique per-trial copies preserve earlier states. Failed artifact writes are ordinary fatal exceptions, never quality rejections. The small `finish_output` helper checks explicit flush and close for every evidence writer; per-iteration history/preflight flushes are also checked.

At the first quality rejection in an iteration, a fresh solve snapshot saves all `n` unscaled increments at 17 significant digits, indexed source components and velocity nodes, accepted state/coordinates, full source event/origin metadata, LSQR status, objective and regularization settings. The all-observation weight table saves the original residuals and fixed row multipliers, together with both native observation/receiver epochs. Every appended original metadata header is prefixed `original_` to prevent collision with derived numerical columns, including the original `station_j`. Model-node rows have no invented event identity. Source units are km and seconds; model increments are dimensionless log slowness. Accepted state metadata explicitly identifies the recorded iteration.

These snapshots address the lost-information problem in the preserved failed Hayward trial: its clamped candidate does not determine the original solve increment. They do not reconstruct an unknown delta from that failed run and do not authorize resuming it. The fixed-weight objective is data residual squares plus log-slowness smoothing; damping remains a linear-solve term, exactly as in the prior implementation.

Independent invented controls are pending. Required coverage includes all-valid numerical/output parity; quality rejection followed by an independently checked acceptable half-step; unique repeated failures; pure and mixed no-evaluable-trial termination; current/final/unexpected and mixed-reason fatal cases; original-delta/clamp/model/weight reconstruction; native cross-epoch and blank/quoted metadata; short-write/close errors and prior-artifact refusal. The harness must exercise this actual candidate loop, with any fixture injection explicitly separated and frozen. No real inversion is authorized by this package.

Drafts `hayward_trial_backtracking_candidate_001` and `_002` are preserved unexecuted source preparations. Draft 001 lacked explicit fresh-artifact refusal. Drafts 001–002 had a duplicate `station_j` weight header; 003 prefixes all original metadata columns and labels the saved accepted state explicitly. No numerical result was produced by any draft.

Adoption is a separate step. The maintained `check_inversion_ray_gate.cpp` still intentionally expects immediate trial failure at `dd_failed_forward_*`; its current/final/mixed/native checks must be retained while its trial expectation is updated after this independent harness passes. A future guarded launcher must explicitly inventory allowed rejected-trial ledgers, each referenced failure/state/solve file and its hashes. A completed run may contain legitimate rejected trials, but missing/orphaned evidence cannot be ignored merely because its filenames differ from fatal failure outputs. The final gate and final numerical/native checks remain mandatory. No current or historical controller is changed here.
