# Final fixed-polygon support readback

Source-only preparation for an independent readback of
[the final action/support calculation](../hayward_cmj_final_tangent_support_001/README.md).
Execution requires its terminal, reaped output and a root `source_review.json`
binding this checker. No evaluator, integration, fit, trace or solver is run.

`check_saved.py` reuses only the hash-pinned stdlib utilities in the prior
[post-half saved checker](../hayward_cmj_post_half_step_tangent_review_001/check_saved.py).
It independently joins the exact final iterator coordinates, authoritative model,
full event/origin/pick/association/channel/epoch context and all 18 catalog uses.
Whole missing component sides are allowed only at the two fixed endpoints;
internal missing components must be exactly the geometry's aligned normals.

Direct eight-node basis evaluations reconstruct every face velocity/normal
polynomial and its whole-patch convex jump extrema. Saved inverse-square
intervals remain source-bound; numerator, tail, length scaling and outward
rounding are checked without reintegration. One exact binary64 mixture is used
for both endpoint moments per patch. All ordinary incident-edge terms are
retained, then the complete vector, physical-box projection and squared norm
are reconstructed. The fit is not repeated or certified optimal. A large
restricted-family witness cannot reject all possible supports.

Final and cached half-edge actions are joined by their original file hashes and
JSON pointers. Identical endpoint pairs cancel exactly. Available C++ component
errors and final C++ action errors are recomputed from saved decimal/hex values.
This checks the final-versus-half action comparison, not every intermediate
approximate decision. Original false/null flags remain unchanged; no
first-arrival, source/model derivative accuracy, field or covariance acceptance
follows.

After source approval and native termination, root may run from the integration
checkout with the recorded Python environment:

```sh
python3 -B data/development/hayward_cmj_final_tangent_support_review_001/check_saved.py
```

The checker exclusively creates `review.json`; root records ownership, terminal
logs and reaping separately. This README records preparation, not a pass.
