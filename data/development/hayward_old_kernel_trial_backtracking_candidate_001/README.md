# Isolated old-kernel trial backtracking candidate

This prospective candidate isolates the trial-handling change from the curvature correction adopted on the integration branch. `before/` contains the complete CMake/source inventory from the frozen failed Hayward run. `after/` differs only in `src/main.cpp`, which is byte-identical to candidate003's reviewed main. The unchanged ray kernel is `7111f67c…`; this package does not restore that kernel into the maintained source tree.

`prepare.py` verifies the archived source, original compiler/runtime libraries, exact native numerical inputs and effective configuration. It records the explicit provenance chain: initial preflight004 main `9f1e6db7…`, the already reviewed original guard main `8a6f1ea8…`, then candidate003 main `a10dcdc…`. All shared kernel headers and CMake match preflight004. The full initial ray-dispatch block is unchanged by the new main-only patch. The earlier guard bridge remains a required part of the argument; the three main files are not claimed identical.

The candidate only retries a trial whose completed failure roster contains pure local-stopping failures. Such rays never enter an objective. Mixed, current-model and final-model failures remain fatal. The original halving sequence, accepted-state reconstruction, fixed weights, clamping, objective comparison and stopping limits remain unchanged. Failure evidence is closed successfully before retry; the first rejection preserves the original unscaled solve and all native weight rows. Increment units are source coordinates in km, origin time in s and model log-slowness dimensionless. An `accepted` trial ledger row means the objective criterion passed, not that the entire inversion succeeded.

No compiler, ray calculation or inverse is run by preparation. Required next checks are a fresh before/after actual-loop suite with all-valid byte parity, the updated existing guard test, the existing external-input test and core validation. Any later real attempt must use a separately frozen binary/input manifest and independent launch review. Reusing initial004 accuracy would cover the unchanged initial operator, not global first arrivals or later three-dimensional accuracy. The original failed inversion, its full-step rejection and the maintained D adoption remain intact.
