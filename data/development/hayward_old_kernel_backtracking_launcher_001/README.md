# Separate old-kernel backtracking launcher

This preparation builds only the reviewed old-kernel candidate: the original `7111f67c…` ray kernel and candidate003 `a10dcdc3…` main. The maintained D kernel, original guarded controller, failed inversion, and running Loma diagnostics are unchanged. No real inverse is launched by this package or its bounded launcher tests.

The initial evidence bridge has two explicit steps: Hayward004 main `9f1e6db7…` to reviewed guarded main `8a6f1ea8…`, then the exact main-only trial-backtracking patch. CMake and the shared mathematical headers are identical to004. Four native numerical inputs and every effective configuration setting must match the reviewed bridge. The original full native support, continuous reference, sampled refinement, finite-difference assessment, identity and initializer requirements remain enforced.

The launcher additionally requires both old-kernel suites and their hash-bound reviews: actual-loop all-valid byte parity and rejection controls, then core/external-input/adapted-guard checks. The completion helper is a byte-exact copy of candidate002 (`8406148e…`), with190 reviewed saved-table controls. It inventories trial ledgers, all rejected-trial states/paths/native identities and the original solve/weights. Pure local-stopping failures alone may be rejected before objective evaluation; current/final, mixed physical failures, unexpected exceptions and failed evidence writes remain fatal. Fixed weights, twelve original halving fractions, source clamps and exponential model updates are unchanged.

The new launcher retains the original process-group cleanup, with one explicit lifecycle correction: it keeps the active group until the supervisor has exited and no live descendants remain. A supervisor exiting with live writers is a failure followed by bounded TERM/KILL/reap; partial hashes are withheld if writers survive. It also accepts the tested STRING/FILEPATH compiler-cache representations while rejecting missing, empty, malformed or duplicate compiler keys. These changes do not alter ray arithmetic.

The complete positive final-table controller path is not established by the completion fixture suite: its launcher tests stop after the child/source prefix because those fixtures use legacy initializers. The helper separately validates an actual completed joint-DD fixture. The real launcher retains the first-arrival initializer requirements and unchanged finite/native final checks. A successful inverse would still be `completed_pending_final_diagnostics`, with `scientific_success=false`; final3D ray, derivative, nonlinear and scientific assessments remain required. No general first-arrival or convergence certificate is inferred.

`prepared.json` records exact source copies, the explicit source map and all directly consumed evidence. Run from a published integration checkout with the evidence archive restored to its original relative paths. Missing evidence fails with a restore instruction; the launcher performs no retrieval, implicit recomputation or substitution. Historical failed-run and004/source/reference packages remain external dependencies. `source_snapshot/` is a review copy; the actual future launcher freezes a separate build from the explicitly pinned candidate directory. A fresh output/build pair and a separate reviewed launch plan are required before real execution.
