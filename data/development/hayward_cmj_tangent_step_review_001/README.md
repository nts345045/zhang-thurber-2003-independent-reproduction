# Terminal saved-output review plan

`check_saved.py` is source only until root reports the native wrapper terminal
and approves this checker. It does not import project numerical modules, run a
helper, recompute a metric or integrate any action/first variation.

The review independently joins complete native contexts and all original
catalog rows/epoch indices, checks every final pin and reaped helper, and
reconstructs these saved-data identities:

- Every midpoint RHS and available tangent component, including both incident
  edges; every emitted direction's decimal/hex agreement and recorded metric
  equation residual, energy and midpoint slope.
- The full nominal and actual rounded-displacement interval contractions,
  fixed endpoints/normals, physical box, positive edges, exact half-edge
  feasibility and separate binary64 multiply/add rounding.
- All starting/trial action sums, unique new-edge records and exact ordered-edge
  cancellation; saved interval metadata retains the fixed integration budget.
- The conservative nominal Armijo inequality with the unchanged binary64
  coefficient, all status/count joins and the two-solve/two-round/2058-edge cap.

Prelaunch sidecar **ordering** is a property of the reviewed source. The saved
checker checks their complete contents and terminal byte bindings; it does not
infer creation time from final filesystem timestamps. Outer wrapper reaping
remains root's owned-session evidence; the checker independently verifies
every helper's recorded return/reaping and the terminal stable-output ledger.

The checker requires a new `source_review.json` with `status: passed`,
`checker_sha256`, `native_summary_sha256`, `native_execution_sha256` and
`outer_reaping_sha256` before it can write a fresh `review.json`. The existing
native `outer_reaping.json` must bind the successful owned tool exit, wrapper
PID, all four terminal hashes, full contexts and reaped helper count. The
checker validates that receipt without independently observing the historical
process. Run once, only after terminal approval:

```sh
PYTHONDONTWRITEBYTECODE=1 /usr/libexec/platform-python3.6 data/development/hayward_cmj_tangent_step_review_001/check_saved.py
```

The result keeps full native identities and exact rational slopes/action bounds.
Original convergence flags remain false and candidate convergence remains
null. This review cannot certify any first arrival, endpoint/model derivative,
local minimum or optimization convergence.
